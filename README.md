# Dictaste for Windows (MVP)

Hold-to-talk path + license polish against **https://dictaste.vercel.app**.

## Status
- Tray app shell
- Global hotkey `Ctrl+Shift+Space`
- Settings: license key, API base
- Polish + paste via `/api/v1/polish`
- Full offline Whisper STT: next iteration (W1)

## Dev
```bash
npm install
npm start
```

## Package installer (on Windows)
```bash
npm run dist
```
